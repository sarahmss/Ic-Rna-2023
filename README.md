# Fundamentos de Redes Neurais Artificiais e Otimização

**Projeto de Iniciação Científica — 2023**  
**Área de pesquisa:** Inteligência Artificial, Redes Neurais e Otimização  
**Grupo de pesquisa:** LaSIA — Laboratório de Sistemas Inteligentes e Aplicados  

## Visão Geral

Este projeto de Iniciação Científica, desenvolvido em 2023, teve como foco o estudo dos fundamentos matemáticos e computacionais das Redes Neurais Artificiais (RNAs).

O trabalho buscou compreender como uma rede neural realiza o processo de aprendizagem, desde sua formulação matemática até a atualização dos parâmetros durante o treinamento. Como parte desse processo, foi desenvolvida uma implementação de uma rede neural **a partir de seus fundamentos**, permitindo estudar de forma prática as etapas envolvidas no aprendizado.

O projeto constituiu a base teórica e computacional para os trabalhos posteriores envolvendo Aprendizado de Máquina, Redes Neurais e aplicações em problemas científicos e de engenharia .

## Conteúdo da Pesquisa

Durante o projeto, foram estudados e implementados os principais conceitos relacionados ao treinamento de Redes Neurais Artificiais, incluindo:

- fundamentos matemáticos de redes neurais;
- representação de neurônios e camadas;
- funções de ativação;
- _forward propagation_;
- funções de erro;
- cálculo de gradientes;
- _backpropagation_;
- métodos de otimização;
- treinamento iterativo de redes neurais.

Também foram estudados diferentes métodos de otimização utilizados no treinamento de modelos, com destaque para:

- **Gradiente Descendente**;
- **Levenberg–Marquardt**.

Uma das principais atividades foi a implementação de uma rede neural  _from_ _scratch_, permitindo relacionar diretamente a formulação matemática estudada com sua implementação computacional.
